# Kantor - NBP Exchange Rates

A Python application that fetches current currency exchange rates from the National Bank of Poland (NBP) and performs currency conversions.

## Features
- Fetches real-time data from NBP (XML format).
- Supports various currencies.
- Simple console interface for easy interaction.

## How to run
1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/Kantor.git
   ```
2. Navigate to the project folder:
   ```bash
   cd Kantor
   ```
3. Run the application:
   ```bash
   python main.py
   ```

## Requirements
- Python 3.x
- `requests` library (install via `pip install requests`)
